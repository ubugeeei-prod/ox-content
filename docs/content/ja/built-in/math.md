# 数式

数式はオプトインです。有効にするまで `$` はリテラルです。

```ts
oxContent({
  math: true,
});
```

`true` と `{}` は同じデフォルトです。省略または `false` では `$` と `$$` はそのままです。

| 形           | ソース         | 結果                                     |
| ------------ | -------------- | ---------------------------------------- |
| インライン   | `$E=mc^2$`     | `<span class="ox-math ox-math-inline">…` |
| ディスプレイ | `$$E = mc^2$$` | `<div class="ox-math ox-math-block">…`   |

ディスプレイ区切りは、段落全体を占めるときだけブロックになります。文中の `$$…$$` はインラインのままです。`<p>` の中に `<div>` を出しません。

出力は静的 MathML です。TeX はほかと同じ HTML エスケープのあと `<mtext>` に入るので、`<script>` や属性風の断片は生 HTML になりません。
