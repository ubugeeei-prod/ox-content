# アクセシビリティ

`ssg.a11y` が有効なとき、テーマ付きページは次を得ます。

- `<body>` 内の最初のフォーカス可能な操作としての **本文へスキップ** リンク
- スキップリンクの対象になるよう `<main>` 上の `id="ox-main"`
- ヘッダー、サイドバー、検索、リーダークロムの余分を隠す印刷 CSS

機能は、オンにするまでオフです。無効なページはスキップリンクも
余分な印刷 CSS も出しません。

```ts
import { oxContent } from "@ox-content/vite-plugin";

export default {
  plugins: [
    oxContent({
      ssg: {
        a11y: true,
      },
    }),
  ],
};
```

`false` または省略すると余分はオフのままです。`true` は既定を有効にします。
オブジェクトは機能を有効にし、スキップリンクラベルを上書きできます。

```ts
oxContent({
  ssg: {
    a11y: { skipLinkLabel: "Skip to main" },
  },
});
```

| 欄              | 既定                | 効果                                        |
| --------------- | ------------------- | ------------------------------------------- |
| `skipLinkLabel` | `"Skip to content"` | スキップリンクのテキスト。HTML 内でエスケープされます。 |

スキップリンクは `class="ox-skip-link"` と `href="#ox-main"` を使います。CSS は
キーボードフォーカスを受けるまで視覚的に隠し、最初の Tab 停止は
スキップリンクになります。

印刷出力は記事を残し、サイトクロムを隠します。ヘッダー、サイドバー、
検索モーダル、コピーや先頭へ戻るなどのリーダークロム操作です。

bare モードはスキップリンクも余分な印刷 CSS も決して出しません。敵対的なラベルは
リンクテキストから抜けられません。
