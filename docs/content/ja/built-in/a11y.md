# アクセシビリティ

`ssg.a11y` を有効にすると、テーマ付きページに次が付きます。

- `<body>` の最初のフォーカス可能要素としての **本文へスキップ**
- スキップ先の `<main id="ox-main">`
- ヘッダー、サイドバー、検索、リーダー chrome を隠す印刷 CSS

省略または `false` ではスキップリンクも追加の印刷 CSS も出しません。

```ts
oxContent({
  ssg: {
    a11y: true,
  },
});
```

オブジェクトでスキップリンクのラベルを上書きできます。

```ts
oxContent({
  ssg: {
    a11y: { skipLinkLabel: "本文へスキップ" },
  },
});
```

既定のラベルは `Skip to content` です。ラベルはエスケープされます。
