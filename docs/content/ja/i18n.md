# 国際化 (i18n)

Ox Content の i18n は次を提供します。

- JSON / YAML の複数ロケール辞書
- ICU MessageFormat 2 パーサ
- ビルド時の静的チェック
- `t()` などを含むランタイム仮想モジュール
- ロケール付き URL（`hideDefaultLocale` が既定でオン）

ドキュメントサイトの本文を翻訳するいちばん簡単な方法は、既定ロケールの Markdown を `content/` に置き、日本語を `content/ja/` に置くことです。`/page` が英語、`/ja/page` が日本語になります。ヘッダーの切替は [ロケールスイッチャー](./built-in/locale-switcher.md) です。

```ts
oxContent({
  i18n: {
    enabled: true,
    defaultLocale: "en",
    locales: [
      { code: "en", name: "English" },
      { code: "ja", name: "日本語" },
    ],
    hideDefaultLocale: true,
    // 辞書が無いサイトでは静的チェックを切る
    check: false,
  },
  ssg: {
    localeSwitcher: true,
  },
});
```

このドキュメントサイトも同じ置き方です。英語は `/…`、日本語は `/ja/…` です。
サイドバーとヘッダーのリンクは、兄弟ページがあるとき現在のロケールに付きます。
生成 API リファレンスは英語のままです。

辞書と MF2 の詳細は英語の [Internationalization](/i18n.md) と [i18n パッケージ](./packages/i18n.md) を見てください。
