# Not By AI badge artwork

Official “Written by Human, Not By AI” light and dark SVGs from
[notbyai.fyi](https://notbyai.fyi).

The copies in this directory were sanitized at vendoring time:

- only `svg` / `path` markup
- no scripts, event handlers, external refs, or `foreignObject`

Do not accept user-supplied SVG through the `notByAi` option. Re-sanitize
before replacing these files.
